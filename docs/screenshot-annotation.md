# 截图与就地标注

按截屏快捷键（默认 `⌃A`），或点击侧栏、菜单栏的“截屏”，直接进入冻结画面。悬停并点击可选中窗口，也可以按住鼠标拖动框选；松手后出现浮动标注栏。拖动选区移动位置，拖动圆形控制点或整条边缘调整大小，再添加标注。左上角标签显示选区坐标和原始像素尺寸。

在 **设置 → 快捷键 → 截屏 → 修改** 中录制自己的组合键。修改立即生效并记住，已有自定义绑定继续沿用；与 Xclip 其他动作、快捷回复的重复组合会提示。与其他软件冲突时，设置页会显示注册失败，可换用其他组合。录制期间本应用的全局快捷键暂停，避免正在录制的组合误触发截屏。

在 **设置 → 快捷键** 中，每个全局快捷键都可点击“清除”来停用，重启后仍保持停用。“修改”可录制新组合并重新启用；“恢复”会移除自定义设置，重新采用默认快捷键，没有默认组合的操作则回到“未设置”。清除截屏快捷键后，仍可点击侧栏或菜单栏的“截屏”。

| 操作 | 方法 |
| --- | --- |
| 调整选区 | `V`，拖动选区、边缘或八个控制点 |
| 精细移动 | 方向键移动 1 像素；Shift＋方向键收缩对应边 1 像素；Ctrl＋方向键扩张对应边 1 像素 |
| 选择当前屏幕 | `⌘A` |
| 矩形 / 椭圆 | `R` / `O`，按住 Shift 约束为正方形 / 圆 |
| 箭头 | `A`，按住 Shift 约束方向 |
| 画笔 / 荧光笔 | `P` / `H` |
| 文字 | `T`，点击选区直接输入；`⌘Enter` 完成当前文字，Enter 换行 |
| 编号 / 马赛克 | `N` / `M`；马赛克属性栏单独调整强度 |
| 修改已有标注 | 选择对应工具，点击标注后拖动；箭头端点和形状四角可再次拖动 |
| 修改文字 | 文字工具下双击已有文字；在原位置编辑 |
| 删除标注 | 选中后 Delete / Backspace，可用撤销恢复 |
| 调整大小 / 粗细 | 属性栏或鼠标滚轮，作用于当前选中标注 |
| 像素取色 | 框选前显示放大镜，`C` 复制颜色，Shift 切换 RGB / HEX |
| 撤销 / 重做 | `⌘Z` / `⇧⌘Z` |
| 复制结果 | `Enter`、`⌘C` 或绿色对勾；调整模式下双击选区也可复制 |
| 保存图片 / PDF | `⌘S` 或保存按钮；格式在设置 → 截屏中选择，取消文件对话框后可继续编辑 |
| 快速保存 | `⇧⌘S`，使用记住的保存文件夹与格式 |
| 取消 | `Esc`；输入文字时先取消当前文字，再按 Esc 退出截图 |
| 返回调整 | 右键先取消标注选择，再退出标注工具，最后清除选框 |

主工具栏为贴近选区的白色单排栏；工具属性单独展开，仅显示适用的颜色、粗细、文字字号或马赛克强度。文字输入框透明并随内容增长，保留原始点击位置。马赛克拖动时预览实际像素效果，导出会将遮挡写入 PNG。复制会存入历史；单独保存不会额外覆盖剪贴板。完成或取消后返回之前的应用；取消不改动剪贴板和历史。

可在任一连接的显示器内操作；本轮不提供横跨多个显示器的一张选区。窗口预选取得冻结画面内的可见区域，窗口被遮挡处也保留屏幕当时的画面。`⌘A` 选择当前屏幕全部内容。旧的截图与 OCR 工具页已经移除，历史图片的编辑与识字入口继续可用。

选区调整保留原始画面和标注，扩大范围可恢复裁剪外内容。新增、修改、移动和删除均支持撤销、重做。画笔和荧光笔仍通过撤销删除；其他基础标注可二次编辑。文字起点被裁到选区外时，先移动文字或扩大选区再双击编辑。

设计参考 [PixPin 静态截图](https://pixpin.cn/docs/capture/static-capture) 和 [PixPin 标注](https://pixpin.cn/docs/mark/base-use)。Xclip 使用现有 AppKit 与本机像素处理实现。

## 完整工作流

工具栏可直接进入贴图、识字、长截图与录屏。更多菜单包含直线、折线、模糊、橡皮擦、聚光灯、水印、放大镜、修复擦除、批量相同文字马赛克，以及翻译、公式、表格和条码识别。可自定义八个常用标注工具；样式按钮设置当前工具的高级属性。

长截图支持横向/纵向、手动滚动和受控自动滚动；录屏结束后可回放、裁剪时间段并导出 MP4、GIF 或 WebP。贴图支持缩放、透明度、旋转、穿透、恢复与再标注。在设置 → 快捷键中分别设置 OCR、长截图、录屏和贴图操作的组合键；新增专用操作默认未分配。

本地 OCR、表格/条码与手工 LaTeX 渲染无需在线服务。翻译与图片公式识别需要在 AI/翻译设置中配置服务，点击提交才发送文字或所选图片。完整功能表、测试证据与限制见 [0.4.0 截图工作流验证](pixpin-complete-validation.md)。

前两个脚本使用合成图片检查几何、像素与离屏组件事件，不读取用户屏幕、不写入系统剪贴板。真实多显示器、系统屏幕权限、中文输入法候选词和跨应用粘贴仍需现场验收。
