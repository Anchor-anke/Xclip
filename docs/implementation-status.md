# Xclip 当前实现与限制

本文件描述 v0.3.0 已接入的代码路径。构建与测试见 [BUILDING.md](BUILDING.md)，本次发布验证见 [RELEASE.md](RELEASE.md)。

| 模块 | 当前能力 | 主要限制 |
| --- | --- | --- |
| 历史与搜索 | 文本、富文本表示、图片、文件；来源应用名称/图标；类型、来源、分类、时间组合筛选；收藏、置顶、删除撤销 | 任意第三方专有剪贴板格式、超大库性能需按实际应用验证 |
| 快速粘贴 | 屏幕底部横向卡片、滚轮浏览、键盘选择、搜索、拖出；右键编辑/收藏/置顶/复制/粘贴/删除 | 自动粘贴依赖辅助功能权限和目标应用；离屏布局测试不等于所有跨应用交互均通过 |
| 工作流 | 栈依次粘贴、快捷回复、拖拽容器、浮动窗口、分类规则 | 栈成功消费取决于实际目标；没有完整团队协作工作区 |
| 截图与 OCR | 屏幕截图、图片 OCR、实况文字、裁剪、标注、手动拼接 | 使用系统 Vision/VisionKit；未集成额外 OCR 插件或自动滚动截图 |
| AI 与脚本 | 可配置兼容接口；独立进程的纯文本 JavaScript 变换、超时和大小限制 | 需要自己的服务配置；脚本没有网络和原生桥接 |
| 局域网共享 | 手动启动 HTTP 会话、临时访问链接、浏览器访问、可选自动发送/接收 | HTTP 未加密；没有设备配对及完整的原生跨设备同步协议 |
| 上传与翻译 | 通用 multipart 上传、DeepL/Google API 配置 | 真实接口、账户、模型与配额需自行配置并验证；不附带凭证 |
| 存储与隐私 | SQLite、独立附件、备份/恢复、迁移路径；捕获排除、暂停、密码和系统身份验证 | 界面锁不加密数据库、附件或备份；删除保留撤销/工作流引用，不保证立即释放全部附件空间 |
| 语言与外观 | 简体中文/English 即时切换并持久化；明暗主题、列表/网格/横向布局；窄窗口筛选换行 | 用户正文与自定义名称保持原文；macOS 自身对话框和外部错误详情受各自语言控制 |
| 分发 | macOS 14+，Apple Silicon/Intel 通用 DMG 与 ZIP | 当前 ad-hoc 签名，未公证；未接入自动更新 |

## 数据兼容

源码目录 `src/OneClip`、应用标识 `local.cclip.app` 和默认数据目录 `~/Library/Application Support/CClip` 保留兼容关系。它们是当前实现的一部分，并非可删除的旧版数据。替换应用包不会主动删除已有历史；备份不包含钥匙串凭证。

## 验证边界

自动回归覆盖存储、权限状态、合成图片 OCR、脚本、HTTP 回环、拦截 API 请求、语言同步和原生菜单/响应链。真实服务连接、多显示器、全部目标软件的粘贴和系统权限仍应结合实际环境验收。

当前系统菜单的最后一轮动态语言切换视觉验收曾因界面工具连接中断而未完成；独立 SwiftUI 实际菜单初始中英文标题及响应链检查已通过。这一限制不会被构建成功或合成测试替代。
