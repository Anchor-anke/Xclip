# Xclip v0.4.0

版本：0.4.0（build 4）。运行要求：macOS 14+，同一安装包支持 Apple Silicon 和 Intel。

## 本次更新

- 截屏快捷键直接打开冻结画面和浮动工具栏，替换原来的截图/OCR 工具页。支持窗口预选、八点调整、精确尺寸、比例、最近选区与延时截图。
- 补齐基础和高级标注：箭头、文字、形状、画笔、荧光笔、编号、马赛克、折线、模糊、聚光灯、水印、放大镜与修复擦除；支持对象二次编辑、撤销重做、属性调整、自定义常用工具和相同文字批量马赛克。
- 新增长截图：横向/纵向拼接、手动/受控自动滚动、预览、撤回、裁剪标注与保存。
- 新增区域录屏：帧率、光标、系统声音、可选麦克风、暂停/继续、回放和时间段剪辑，导出 MP4、GIF 或 WebP。
- 新增贴图工作流：缩放、透明度、置顶、锁定、鼠标穿透及恢复、旋转翻转、再标注、OCR 与关闭后恢复。
- 截图直接进入本地 OCR、表格或条码识别；翻译与图片公式识别使用自行配置的服务。LaTeX 预览及 PNG/MathML 导出使用随包离线资源。
- 截屏、OCR、长截图、录屏及贴图操作均可在“设置 → 快捷键”修改。保留已有绑定，新专用操作默认未分配。
- 本地构建安装器复用稳定签名、固定路径原子替换，并在校验版本、证书与进程状态后清理已知旧应用副本。修复隐藏状态下录屏和贴图窗口的显示。
- 默认历史条数调整为 100，可在设置修改；修复公开构建中日志携带本机源码路径的问题。

## 下载与安装

[Release 页面](https://github.com/Anchor-anke/Xclip/releases/tag/v0.4.0) 提供：

- `Xclip-v0.4.0-macOS-universal.dmg`：打开后将 Xclip.app 拖入 Applications。
- `Xclip-v0.4.0-macOS-universal.zip`：解压得到 Xclip.app。
- `SHA256SUMS`：下载两个包后，在该目录运行 `shasum -a 256 -c SHA256SUMS`。

完整退出旧版后再替换应用，保留原有历史与设置。0.4.0 使用稳定的本地开发证书，未经过 Apple Developer ID 签名或公证。从旧 ad-hoc 版本升级可能需要为实际安装路径重新授予屏幕录制权限；已有图片 OCR 无需此权限。详见 [BUILDING.md](BUILDING.md)。

旧副本自动清理属于仓库的本地构建安装流程。DMG 拖放安装没有在线自动下载更新或跨目录自动删除应用的能力。

## 验证与边界

完整功能回归和应用冒烟通过；另补充快捷键本地化 87 项、贴图 80 项、截图交互 133 项和录屏准备窗 7 项定向检查。测试使用合成内容、隔离剪贴板与本地资源，不附带用户历史、密钥或服务凭证。完整功能表及证据范围见 [截图工作流验证](pixpin-complete-validation.md)。

本轮真实屏幕框选、箭头绘制和改色已验证；最终修订版的快捷键名称已现场确认。最后一轮截图/录屏现场复查因界面验收工具断连未完成。多显示器、macOS 14 实体麦克风、第三方网页自动滚动及线上模型识别质量仍需对应环境验收。

翻译和图片公式识别需要自己的 API/模型配置。表格按识别文字的位置还原单元格，复杂合并单元格需要核对；修复擦除使用本地像素扩散，适合平滑背景。录屏上限为 30 分钟/2 GB，动图最多 1800 帧。

## 构建和后续发布

1. 在 `src/Xclip.xcodeproj/project.pbxproj` 更新版本和 build。
2. 执行 `./src/build.sh` 与 [开发指南](BUILDING.md) 列出的回归。
3. 执行 `./scripts/package-release.sh`，核对 DMG 和 ZIP 中的版本、架构、签名、资源及哈希。发布未安装的候选包时，可设置 `XCLIP_PACKAGE_APP` 为完整 `.app` 路径。
4. 将源码提交到 main，为同一提交创建版本标签与 GitHub Release，上传 `dist/` 中的两个包和校验文件，再核对远端提交及下载校验值。

构建产物、本机授权记录和本地执行日志不进入源码提交。
