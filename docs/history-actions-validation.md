# 剪贴板历史按钮修复验证

日期：2026-09-16。

## 问题与修复

1. **列表鼠标单击不能选中记录。** 在真实隔离应用中，点击第一行和第二行均不改变选择，方向键却可以选择；多个依赖选择的底部按钮和右上角菜单项因此一直禁用。移除行级点击手势，改用 List 原生的选择、上下文菜单和双击主操作。修复后真实鼠标单击可选中并切换行，⌘A 可多选，按钮状态随之更新。
2. **筛选后的旧选择仍启用操作。** 操作目标统一从当前结果派生，并同步清除不再可见的 UUID。实测全选三条后输入无匹配查询，结果归零且所有选择操作禁用；清除筛选恢复三条记录，不恢复旧选择。
3. **右上角两个菜单缺少状态提示。** 搜索历史为空时显示“暂无搜索历史，搜索后按回车保存”；更多操作在未选中时提示先选择内容。空分类菜单提供设置入口。
4. **操作已执行但缺少反馈。** 复制、入栈、加入容器、保存快捷回复、导出均报告实际结果；存储失败与复制脚本警告不会被成功提示或旧错误遮盖。工作流更新先成功落盘再发布到界面。
5. **拖拽入口单击没有反馈。** 文案改为“按住拖出”，单击显示拖动说明，空选择具有禁用语义；原生拖拽及 5 px 阈值保留。

List 事件处理依据：[Apple 的原生选择及双击主操作说明](https://developer.apple.com/documentation/swiftui/view/contextmenu%28forselectiontype%3Amenu%3Aprimaryaction%3A%29)。本机 macOS 26.5 SDK 也确认此 API 支持 macOS 13 及以上。

| 操作 | 实际观察 |
| --- | --- |
