# PixPin 工作流补全 · 0.4.0

0.4.0 的截图工作流参考 PixPin 的界面及官方截图、标注、贴图、长截图、录屏和公式文档。Xclip 使用自己的代码、身份和服务配置。

## 功能入口与实现

| 工作流 | 当前入口与行为 | 验证范围 |
| --- | --- | --- |

| 基础标注 | 画笔、荧光笔、矩形/椭圆、线/折线、箭头、文字、编号、马赛克 | 真实像素渲染、二次编辑、撤销/重做 |
| 高级样式 | 填充/圆角/圆弧、虚线/端点、箭头型、颜色透明度、文字字体/粗斜体/描边/背景/换行/旋转、序号样式 | 渲染及交互测试 |
| 图像效果 | 模糊、橡皮擦、聚光灯、水印、独立取样区放大镜、修复擦除 | 原图重放、预览/导出一致性；修复擦除为本地像素扩散，不是生成式 AI 重建 |

| 保存 | PNG/JPEG/HEIC/TIFF/PDF、质量、圆角、阴影、记忆文件夹 | 真实编码/解码与 PDF 页尺寸 |
| 贴图 | 无边框窗口、拖动、缩放、透明度、锁定、置顶、鼠标穿透与恢复、旋转/翻转、缩略、原图/当前图复制保存、再标注、OCR、关闭恢复 | 像素变换与隐藏原生窗口生命周期 |
| 剪贴板贴图 | 图片、文字、颜色、文件；LaTeX 分隔文本经本地公式渲染后贴图 | 命名剪贴板测试与本地 WebKit；不自动读取外部服务 |
| OCR / 表格 / 条码 | 工具栏直接进入可编辑结果窗；支持语言选择、单元格编辑、文本/TSV 保存 | 真实合成图片 OCR、二维码解码；表格按文字位置恢复单元格，复杂合并单元格需核对 |
| 翻译 | 识别文字后选择目标语言，显式提交到项目 AI 模型或 DeepL/Google API | 请求构造回归；未进行真实线上请求，未验证线上翻译质量 |
| 公式 | 显式提交选区到已配置视觉模型，LaTeX 可编辑、预览、保存，PNG/MathML 复制、贴图 | 本地 KaTeX/WebKit 与导出实测；图像识别依赖用户配置视觉模型 |
| 长截图 | 横纵采集、手动滚动、受控自动滚动、预览、撤回、重新开始、裁剪标注、复制保存贴图 | 合成源像素一致性、2× Retina、错误恢复、目标切换/遮挡保护及取消 |
| 录屏 / 动图 | 区域、帧率、倒计时、光标、系统音频、麦克风、暂停/继续、结束回放、剪辑、MP4/GIF/WebP | 合成 H.264/AAC 编解码、双音轨、实际 GIF/WebP 编解码、取消与资源清理 |
| 快捷键 | 设置 → 快捷键：截屏、OCR、长截图、录屏、剪贴板贴图、恢复/显隐/穿透恢复 | 保存兼容、冲突检测；新增专用快捷键默认未分配，避免抢占已有组合 |
| 更新 | 固定应用路径与证书；安装器校验后原子替换并清理已知旧应用副本 | 保留上一轮安装/签名测试，本轮完整回归及安装证据追加在下方 |

## 依赖与边界

- 翻译及图像公式识别需要在应用中配置服务/模型，并由用户显式提交文字或选区；手工 LaTeX 编辑和渲染可离线使用。本次验收未向外部服务发送真实截图，未验证在线识别质量。
- 静态公式资源为随包分发的 KaTeX 0.18.7；没有 CDN 依赖。动画 WebP 使用随包分发的 universal libwebp 1.6.0 helper，不依赖用户 PATH 上的 ffmpeg/cwebp。
- 录屏兼容 macOS 14：麦克风通过 AVCaptureSession；macOS 15+ 使用 ScreenCaptureKit 麦克风流。类型检查与合成音频测试不能代替 macOS 14 实机权限验收。
- 录屏限制 30 分钟、2 GB；动图最多 1800 帧。长截图与标注有像素和历史预算，达到上限会报可恢复原因。
- 多显示器、外接音频设备和真实第三方网页的行为需要现场验收；合成测试不会被当作这些环境的实测证明。

## 发布包验证

公开发布前将日志默认来源宏从 `#file` 改为 `#fileID`，重新构建 0.4.0（构建 4）；应用包扫描确认不含开发机绝对路径、数据库、日志或所检查的私钥标记。此次重建不改变截屏工作流。

DMG 通过 `hdiutil verify`；DMG 挂载和 ZIP 解压后的 81 个应用文件逐一与发布输入哈希相同，主程序和两个 helper 均为 arm64/x86_64，所有架构严格验签通过。发布输入的隔离应用冒烟测试通过，包含 96 项应用检查及语言、快速粘贴、菜单和来源记录检查。最终安装包的 SHA256 见 GitHub Release 的 `SHA256SUMS`，发布输入主程序 SHA256 为 `d4e1e9a0fa419fd53a3b7427c0f306fa34dab66b5d65110de5673c4d05978498`。
