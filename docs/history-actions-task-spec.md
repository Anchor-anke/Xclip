# 任务：修复桌面剪贴板历史界面的无响应操作

## 目标
让剪贴板历史界面的可用按钮执行对应操作，并显示必要的结果或受限原因。

## 用户已提供的上下文
- 桌面端剪贴板历史有多个按钮点击没有反应，要求优化。

## 范围内
- 检查历史列表、网格、横向布局的选择与按钮状态。
- 修复真实 QA 中复现的列表单击无法选择、方向键可以选择的事件冲突。
- 修复筛选后失效的选中项、空搜索历史菜单和缺少操作反馈的问题。
- 明确批量拖出入口的操作方式。

## 范围外
- 与本问题无关的整体改版和新功能。
- 发布版本和清理用户历史。

## 用户约束
- 遵守提供的 AGENTS.md；没有 .codegraph 时跳过 CodeGraph。

## 系统假设（不是用户事实）
- 保持现有视觉样式、历史数据和设置；在现有未提交改动上增量修复。
- 先修复代码中可以确认的问题；具体无响应按钮仍可由用户补充。

## 未确认项
- 用户遇到问题的具体按钮与布局。
- 正式安装版的验收状态；隔离 QA 已成功连接，初始连接失败已恢复。

## 验收标准
- 筛选、删除、取消收藏后，按钮只操作当前有效选择；没有有效选择时显示禁用状态。
- 鼠标单击能够选择与切换列表记录，原生多选和双击粘贴互不抢占。
- 空搜索历史有明确提示，筛选无结果时可重置。
- 复制、入栈、保存等动作成功时提供可见反馈，失败信息不被成功提示覆盖。
- 批量拖出明确说明按住拖动，单击不再没有反馈。
- 原有复制格式、附件拖拽、选择和快捷键行为保持可用。

## 验证要求
- 针对选择变化和批量操作执行回归检查。
- 编译完整应用并运行现有隔离 smoke 测试；不修改正式数据或系统剪贴板。
- 通过桌面自动化复核实际界面；工具不可用时单独记录未完成的验收边界。

## 交付物
- 源码修复、必要的回归测试和验证记录。

## Agent 行为
- 执行前先检查当前仓库现状。
- 实现前先给出计划。
