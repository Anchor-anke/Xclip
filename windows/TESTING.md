# Windows 验证方法

核心测试入口：`dotnet run --project windows/Xclip.Core.Tests -c Release`。Windows 构建与架构匹配的隔离窗体 smoke 由 `build.ps1` 及 GitHub Actions 执行；跨架构编译不代表在目标设备运行。实际桌面验收仍需以下检查。

## Windows 实机验收清单

先使用不含真实敏感信息的文字、生成图片和临时文件；测试结果应记录系统版本、x64/ARM64、显示器分辨率和缩放比例。

1. 解压完整包，启动 `Xclip.exe`。确认主窗和托盘可见；关闭/Esc 隐藏；托盘能恢复；重复启动只打开已有实例；退出后快捷键释放。
2. 在记事本、浏览器、画图、资源管理器复制中文多行、图片和多个临时文件。确认历史类型、预览、来源、搜索和去重；重启后内容及收藏/置顶仍存在。
3. 暂停记录后复制内容，立即恢复，确认暂停期间内容不入库。使用支持排除标记的密码管理工具时核验该标记行为，不假定所有密码都会自动排除。
4. 在目标编辑器中按 `Ctrl+Alt+V`，搜索、方向键选择、Enter 粘贴。检查中文输入法、按住 Enter、右键粘贴、快速切换窗口及目标关闭时的行为。管理员窗口自动粘贴失败应有复制退路，不能误贴到其他窗口。
5. 右键收藏、置顶、删除；验证 UUID 对应条目正确。清理仅删普通条目；立即撤销可恢复。发生新采集后撤销失效的提示和按钮状态应准确。
6. 按 `Ctrl+Alt+A`，反向拖选、八点调整、跨边翻转、移动与方向键微调。添加箭头、中文多行文字、覆盖到末端边缘的马赛克；逐步撤销；完成后在画图粘贴并另存 PNG，核对尺寸和真实像素。
7. 检查截图取消、取消保存、保存到不可写位置、第二次截图请求，确认不会卡住或丢失当前编辑；保存文件应不含工具栏和选区外区域。
8. 在 100%/150%/200% 缩放、左侧/上方副屏负坐标和混合 DPI 下重复截图及主窗操作；确认工具栏可见、选区不偏移、中文输入框可读、输出不缩放。
9. 使用单段大文本、多张图片、300 条普通历史和已收藏图片，观察面板滚动、搜索、后台复制和重新打开的性能。
10. 退出后备份 `%LOCALAPPDATA%\Xclip`，使用另一测试副本检查损坏历史报错保留；确认便携程序目录更新不影响原数据。不要用真实主历史做破坏性测试。

## 验收边界

`Xclip.exe --smoke-test` 不访问系统剪贴板或桌面；它检查隔离窗体、INPUT 结构尺寸，以及用生成棋盘图执行的裁切、八点几何、箭头文字、马赛克边缘和撤销合成。即使 Windows CI 后续通过，也只代表这些有限检查，不能替代上面的真实桌面与跨应用验收。

首版范围及使用限制见 [Windows 说明](README.md)。未将 OCR、录屏、长截图、AI、备份互通或完整 macOS 功能迁移列为已完成。
